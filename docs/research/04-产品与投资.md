# 04 · 产品能力 × AI 与 投资 × AI

> 覆盖方向 5（PRD/用户研究/原型验证/MVP）+ 方向 6（行业研究/尽调/信息源管理）

## TL;DR

1. **AI 做 PRD 的正确姿势是"先锁资料、再让 AI 提问、最后才生成"**：墨刀教程给出了可复制的三步法；直接说"给产品加个 AI 助手"只会得到格式完整但业务规则全靠编的 PRD。
2. 产品工作流正在整体 Agent 化：官方范本（Anthropic AI-Native SDLC playbook）+ 社区范本（Agent-Playbook 的 PRD-with-agents）都把"需求文档驱动 + 分阶段 gate"作为主线。
3. **投资研究的 AI 化已有开源范式**：AlphaInsight（LangGraph 多 Agent 尽调：规划→检索→杜邦分析→做空 Agent 辩论→主笔报告，引用溯源到 PDF 段落）可直接改造为个人投研流水线。
4. 机构级信号：AlphaSense 尽调工作流、Citadel 面向个人投资者的 AI 工具、Orbit Flex 把"对冲基金级研究"平民化——个人投资者与机构的工具差距正在快速收窄。
5. 共同心得：AI 时代投研/产品的核心竞争力从"找信息"变成**"设计问题 + 验证来源 + 保持怀疑"**（做空 Agent 与"挑刺者"角色是多 Agent 系统的标配）。

## 一、产品 × AI：从想法到 MVP 的加速实践

### 1.1 PRD：墨刀三步法（国内可复制的实操教程）

来源：https://modao.cc/ad/blog/ai-prd-tutorial-for-pm.html

反例开篇：把"给在线教育产品增加 AI 学习助手"直接交给 AI，会得到一份**自行增加跨课程搜索、历史记录、自动批改等从未被讨论功能**的 PRD——格式完整、业务失控。

正确流程（原文方法，案例即"AI 学习助手"——与用户的 tutor 项目直接相关）：

1. **准备四份材料**：S1 需求范围（谁能用/入口/角色）、S2 内容资料（真实课程片段样本）、S3 业务规则（只依据当前资料回答；无依据提示未找到；不自动代交作业）、S4 已有约束（不新增计费/跨课搜索/教师后台）。
2. **先让 AI 提问而不是生成**："请先阅读资料，暂不生成完整文档。输出：已确认的目标/角色/范围/规则；会影响流程的冲突或缺失资料及要向谁确认；本期不做的功能。每条标注依据 S1–S4。不要补造调研数据、技术架构、性能数值。"
3. **分三次生成**：整理需求输入 → 生成规则与流程 → 补齐异常与验收（含验收用例表）。

关键纪律：**每条需求至少能指回一份材料；找不到来源的新增功能先成为问题，不自动进入本期范围**；未决事项（保存期限、长度上限）放进未决清单，禁止 AI 编造"看起来合理的数字"。

### 1.3 用户研究与原型验证的加速做法（综合上述来源 + 02 篇案例）

- **用户访谈**：用 AI 先生成访谈提纲假设树 → 访谈录音转写 → 让 AI 按假设树编码归纳，但结论必须回到原始引语核对（防止 AI 幻觉污染定性数据）。
- **冷启动验证**：seeu.food 的 Reddit 高 karma 私信法（https://developer.volcengine.com/articles/7589192954821279770）——文案与流程全部用 AI 先跑通，人只负责执行与记录。
- **MVP 迭代节奏**：金浩斌"2 天玩法原型 + 7 天上架"（http://www.gamelook.com.cn/2026/08/599286/）与 Base44"删功能使激活翻倍"（https://cloud.tencent.com/developer/article/2538775）共同指向：验证单位从"版本"缩小到"假设"。

## 二、投资 × AI：行业研究与尽调自动化

### 2.1 开源范本：AlphaInsight 多 Agent 尽调系统

来源：https://github.com/Robot-Nav/AlphaInsight （项目自述，基于 LangGraph）

流程拆解（对个人投研极具参考价值）：

1. **规划 Agent**：把目标公司指令拆解为宏观/财务/合规三大维度的"检索意图树"。
2. **情报检索 Agent**：并发调用 SEC、新闻、RAG 知识库，召回近 3 年财报与纪要。
3. **财务分析 Agent**：长链推理 + 杜邦分析挖掘利润下滑根源。
4. **风控做空 Agent**：专门扮演"挑刺者"，与财务 Agent 多轮辩论（质疑营收增长下的供应商集中与存货周转矛盾），迫使系统反思。
5. **主笔 Agent**：3–5 轮辩论后汇总共识与分歧，调 Python 绘图，输出**引用溯源到 PDF 段落**的 20 页深度尽调报告。

同类模板：n8n 的尽调报告工作流（LlamaIndex + Pinecone，https://n8n.io/workflows/13501-generate-due-diligence-reports-with-llamaindex-pinecone-and-gpt-5-mini/）；学术侧的多 Agent 创投分析框架（LLM + 知识图谱编排，https://zenodo.org/records/20258400/files/IJSRED-V9I3P48.pdf）。

### 2.3 个人投研流水线（可直接照抄）

```
信息源管理          研究                验证              输出
 │                  │                  │                │
RSS/newsletter     规划Agent拆         做空Agent辩论      带溯源的报告
自动入库(歸藏模式)   意图树 → 检索Agent   交叉核对原始PDF    (引用到段落)
+ RAG 知识库        并发检索(SEC/新闻    关键数字回查       + 观察清单
                    /公告/研报)         一手来源           周更
```

三条纪律（综合 01 篇上下文工程 + 2.1 范本）：

1. **每个结论必须能点击回原文**（AlphaInsight 的段落级溯源是硬要求）；
2. **永远保留一个"敌方 Agent"**（做空 Agent / 挑刺者），防止确认偏误；
3. **信息源清单本身是资产**：顶级用户维护的是"我信任的 20 个一手来源 + 自动爬取技能"（歸藏：skills 自动爬取常看的 newsletter/网站/邮件）。

### 2.4 如实说明

- 国内买方（公募/私募）如何用 AI 做投研的**一手**公开材料本期未检索到足够样本（多为厂商宣传：如 RESSET 金融大模型 https://manual.resset.com/RESSETFLL.pdf），第二期考虑从私募访谈/招聘 JD 侧切入。
- AI 对二级市场收益本身的增益缺乏可审计证据，本篇只覆盖"研究流程加速"，不构成任何投资建议。

## 三、对用户的落地意义

- 你的 tutor 项目可以直接套用墨刀 S1–S4 材料法写第一版 PRD（材料 S2 就用你自己的学习笔记），再用 Agent-Playbook 模式让子 Agent 出多版本草稿对打。
- 投资学习的第一课不是看盘，而是**搭一条自己的投研流水线**：从"看别人的报告"升级为"AI 帮我生成带溯源的报告，我负责验证与判断"——这本身也是 tutor 项目"如何教人学习"的元方法。
