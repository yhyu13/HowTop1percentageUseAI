# 03 · 游戏开发 × AI 与 AIGC 工作流

> 覆盖方向 3（游戏开发 × AI）+ 方向 4（AIGC 工作流）。用户本人是游戏开发者，本篇是最"贴身"的一篇。

## TL;DR

1. **独立游戏开发的全岗位 AI 化已经完成闭环**：策划（玩法融合原型 2 天）、程序（TapTap Maker/自然语言编程）、美术（AI 抽卡 + 人当主美）、音频（AI 生成 BGM "爆杀"两个月自学的编曲）、测试（LLM 自动化 playtest 论文已发表于 FSE/ASE 2025）——金浩斌兄弟 4 个月 4 款游戏是当前最有细节的一手样本。
2. **TapTap 制造是国内对独立开发者最重要的变量**：黄一孟直播演示 1 人 1 小时做 3 款游戏；平台逻辑是"开发者是老板、AI 是制作人"，把 70% 的"搓零件时间"重新分配给想法（60% 想法 + 40% 优化）。
3. **但分发仍是生死线**：TapTap 论坛一手复盘显示"产品做好了自然有人玩"是幻觉——日曝光 100 上下，缺的是分发不是产品；中小开发者的对策是"点开就能玩"的小组件、新品榜单与社区运营。
4. **AIGC 工作流正从"单点生成"走向"资产化管线"**：提示词库、风格 LoRA、工作流文件成为可版本管理的资产；腾讯 VISVISE 已发布业界首个 AI 全流程 3D 角色动画管线（骨骼→蒙皮→动画→插帧，数日压缩到分钟级）。
5. 3A/工业级管线与个人管线正在合流：腾讯混元开源的游戏 AI 生成工具宣称 RTX 4090 就能制作 3A 级动态内容——个人开发者的上限被大幅抬高。

## 一、独立游戏全管线 AI 化：三个一手案例

### 1.1 出头喵工作室：4 个月 4 款游戏（TDW2026 演讲实录）

来源：http://www.gamelook.com.cn/2026/08/599286/ （GameLook 整理的演讲全文）

| 游戏 | 周期 | 备注 |
| --- | --- | --- |
| 小丑牌 × 2048 融合 | **7 天**（其中 2 天出可玩原型） | 首次接触手游与 AI 编程，零程序员 |
| 玩法融合第二款 | 13 天 | 验证 IAA 广告变现，"收入不菲，超级划算" |
| 二次元放置卡牌 RPG | 50 天 | 几乎全部美术资产由 AI 产出；首次做服务端游戏 |
| 聚光灯赛题"跳跃" | 10 天 | **新品榜第三**；策划内容也开始交给 AI |

- 背景对照组：转型前做 Steam 塔防《元素与构筑》，3 人 × 1 年，销量 1 万份；期间两次换程序（第一个程序"做着做着回老家结婚去了"）。
- 四大传统痛点的 AI 解法：**程序**（拥有"完全听话的 AI 程序"，消灭策划-程序吵架）、**美术**（兄弟是 UI 美术不会画画 → AI 抽卡他来挑，定位变成"主美"）、**音乐音效**（原报价 3–4 首 BGM 数千到一万元，现 AI 几分钟生成）、**学习成本**（连续做 4 个不同类型的游戏本身就是学习）。
- 平台红利：无买量、TapTap 免费曝光、变现零门槛、零成本入场——"做出来已是最大收获"的正向循环。

### 1.2 TapTap 制造：平台级的"AI Native"实验

来源：https://news.17173.com/content/02072026/023954968.shtml （17173 深度报道，含直播演示与黄一孟访谈）

- 直播演示：黄一孟一人、像微信聊天一样描述需求，**1 小时做出沙盒、AVG 两款新游戏并优化一款飞行射击的特效**，每几分钟出一个带美术与音效的可玩 demo。
- 战略引用米哈游蔡浩宇的判断：未来只有两类人做游戏有意义——前 0.0001% 的天才团队，和 99% 为满足自己想法创造的业余爱好者；TapTap 选择服务后者。
- 时间重分配：传统流程 10% 提想法 / 20% 改方向 / 70% 搓零件；AI Native 后 60% 提想法 / 40% 优化想法。
- 学习公式："立刻创作 + 实时反馈 = 有趣学习"。
- 平台结构四件套：决策大脑（大模型，可替换/组大脑群）、知识库（过往项目沉淀，参与人越多越强）、工具素材（星火编辑器）、市场对接（TapTap 一键发布闭环）。
- 开发者侧生态事实（TapTap 制造论坛一手帖）：
  - 《水彩魔法师·水排序》一人 + AI（水排序 + 剧情 + Boss、100 关）上线复盘：**日曝光 100 上下**、小红书图文无水花；教训是"这类游戏本质是流量产品""缺的是分发、不是产品"；最忙一天推 9 个版本（后来知道频繁发版会触发系统重抓数据）；对策是铺小红书"点开就能玩"小组件（免备案、笔记即玩）。（https://www.taptap.cn/moment/853728463025082019）
  - 《灵植仙途》：纯代码小白用详细设计文档驱动 TapTap 制造，**7 天、204 次构建、约 24400 行代码**做出修仙种田游戏（70 种灵植/52 位 NPC/63 件法器/5 种结局）。（同论坛）
  - 社区已自发讨论"积分 = token"的成本优化（从每次 2000 积分降到 50 的经验帖）——说明用自然语言做游戏同样需要上下文工程素养。

### 1.3 Tripo 案例：两周单人 UE5 光枪 demo

来源：https://www.tripo3d.ai/blog/two-week-solo-game-dev （当事人第一人称复盘）

- 工具栈全景（每个环节都有 AI）：**策划** ChatGPT + Gemini（点子、设计文档、逐日排期）；**概念美术** DeepSeek + Midjourney（含风格指南）；**编程** ChatGPT 当"实时 Blueprint 教练"；**音频** 生成式音乐 + 音效模型；**配音** TTS；**3D 建模** Tripo。
- 方法论：第 1 周只做一件事——立起能证明"枪 + 光剑"核心循环的最小 MVP 关卡；设计文档由 Gemini 几小时出初稿，人在腾讯文档里每晚维护活清单。

## 二、AI × 游戏测试（独立开发者容易忽视的一环）

- FSE 2025《Towards LLM-Based Automatic Playtest》：把 LLM agent 当玩家做自动化试玩（https://dl.acm.org/doi/abs/10.1145/3696630.3728700）。
- ASE 2025《MIMIC》：给 LLM 注入多样人格特质做更好的游戏测试（https://dl.acm.org/doi/abs/10.1109/ASE63991.2025.00012；预印本 https://browse-export.arxiv.org/pdf/2510.01635 结论：人格驱动 agent 自动测试"有前景也有明确局限"）。
- 开源工具 GameEval：浏览器自动化 + LLM 四阶段管线（加载验证→控制发现→玩法探索→质量评分）评估网页游戏（https://github.com/adam0white/GameEval）。
- 对用户的直接可操作版本：给自己的 web 游戏写一个 Playwright + LLM 的"AI 试玩员"，每晚跑冒烟测试——这与 01 篇"睡前派活"模式天然契合。

## 三、AIGC 工作流：从单点生成到资产化管线

### 3.1 提示词与工作流的资产管理

- ComfyUI 生态已出现一批"提示词资产库"节点：`comfyui-prompt-library-nodes`（结构化提示词库 + 可移植工作流 + LoRA 元数据组合，https://github.com/2223290690z-hue/comfyui-prompt-library-nodes）、`ComfyUI-4A-Prompt-Manager`（https://github.com/tsukino4a/ComfyUI-4A-Prompt-Manager）、`ComfyUI-PromptPresetManager`（https://github.com/yurishk/ComfyUI-PromptPresetManager）、`prompt-concatenate-pro`（正负向成组管理，消灭"提示词意面"，https://github.com/StoneZol/prompt-concatenate-pro）。
- 歸藏公开维护自己的 prompt 仓库（github.com/op7418/guizang-s-prompt），并记录了 2025 年图像工作流的演进路径：**ComfyUI 教程 → GPT-4o 图像 → Nano Banana / Nano Banana Pro → Kontext → Seedream 4.0**——即从"节点式生成"迁移到"对话式编辑"，一致性由模型原生能力 + 风格资产共同解决。（https://m.163.com/dy/article/KI24JDV30556BM3X.html）
- 实操共识（综合上述来源）：风格一致性 = 固定 seed/LoRA + 风格指南图（Midjourney style reference）+ 提示词模板库三者叠加；单靠文字描述不可复现。

### 3.2 工业级 3D/动画管线（天花板正在抬高）

- 腾讯游戏 VISVISE 在 SIGGRAPH Asia 2025（香港）发布**业界首个 AI 全流程 3D 角色动画制作管线**：智能骨骼生成（人形/四足/枪械/怪物，一键生成主骨骼 + 飘带裙摆辅助骨骼，数日→分钟级）、智能蒙皮、3D 动画生成、智能插帧，成果可直接导入现有游戏生产管线。（http://www.nadianshi.com/2025/12/402087 、https://news.17173.com/c/tg/content/12182025/154602864.shtml）
- 腾讯混元开源游戏 AI 生成工具，宣称 RTX 4090 消费级显卡即可制作 3A 级动态内容。（https://hub.baai.ac.cn/view/48166）
- 对独立开发者的含义：3D 资产成本曲线陡降，"个人做 3D 游戏"的门槛从技术转移到品味与分发。

## 四、给用户的游戏侧工作流建议（蓝图）

```
创意        玩法原型        内容量产         测试            分发
 │            │              │              │              │
ChatGPT/    TapTap Maker    AI美术抽卡+     LLM playtest    小红书组件
Gemini 融合  或 Claude Code  人工主美挑选     (Playwright)    + TapTap 社区
点子池       2天出原型      + 音乐TTS        每晚定时跑      + 新品榜
```

- 原则 1：把"程序岗"永久外包给 AI（金浩斌模式），自己保留策划判断与主美职能。
- 原则 2：每款游戏限制在 7–50 天周期内（对应出头喵四款游戏的实测区间）。
- 原则 3：从第 1 天就准备分发素材（TapTap 论坛一手教训：首发 3 天黄金窗口不可浪费）。
- 原则 4：美术资产入库管理（seed/LoRA/提示词模板/风格参考图四件套），跨项目复用。
