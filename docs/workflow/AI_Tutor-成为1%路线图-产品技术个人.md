## 2. "1%" 的三层定义（这是你和 CEO 对话的统一语言）

**第一层 · 使用者维度：把 AI 当系统经营。**
标志：规则文件 + 记忆 + 子 Agent + 定时任务 + 资产库。→ 你已达标，这是你的"技术信誉"。

**第二层 · 产品维度：教育引擎而非聊天外壳。**
标志：**学习者模型（知识追踪 + skill gating）+ 苏格拉底护栏（反退化）+ 可量化学习增益 + 一键交付教师/家长报告**。→ 当前缺前两项的工程化。这是"1% 教育产品"与"99% AI 聊天套壳"的分界线（Khanmigo 的教训：没有 skill gating 就不是产品）。

**第三层 · 组织维度：可度量、可复制、可分发的机器。**
标志：北极星指标 + 单位经济 + 分发回路 + 合规底线。→ 当前是 7 年财务模型 + 单体产品，缺"可展示的增长引擎"。

**一句话对 CEO：我们不是在做"AI 版作业工具"，我们在把 Bloom 2-Sigma（一对一辅导超越 98% 课堂）用 AI 变成可规模化的产品。**

## 3. 战略诊断：楔子、护城河、不做什么

### 3.1 机会（调研支撑）
- `AI+教育`被指近万亿市场、千亿级赛道（21 世纪经济报道 / 财联社）；Duolingo 靠 AI 上调全年收入指引、股价单日 +30%→ 需求与商业化被验证。
- 全球理论把手：**Bloom 2-Sigma**；世界银行尼日利亚 GPT-4 课后辅导实验报告大幅学习增益。
- 国内大厂火力集中在 K12 应试与学习机硬件；**"小学 + 项目式学习 + 教师零负担"是稀疏带**。

### 3.2 楔子（Wedge：从哪一点切入）
> **"教师输入一个主题，AI 为每个学生生成专属项目，并在 6 节课里把孩子从'要答案'引导成'会探究'。"**

这是别人没有的组合：Khanmigo 绑课程、Duolingo 单一学科、豆包只会给答案、学习机是题库+硬件。你的楔子 = **个性化项目生成 + 苏格拉底引导 + 教师 10 分钟**。

### 3.3 护城河（凭什么别人打不进来）
1. **学习者模型**：知识追踪 + 掌握图谱 + 前置门控 → 数据越用越准（通用聊天给不了）。
2. **反退化的品牌**：可量化的"答案泄露率"与"探究能力成长"→ 家长/学校的信任资产。
3. **学校信任与转介绍**：B2B 的护城河是渠道与口碑，不是代码。
4. **作品广场的增长回路**：学生作品可分享互评 = 天然的病毒循环。

### 3.4 反模式（明确不做）
- ❌ 拼功能数量（通用聊天免费碾压）。
- ❌ 用"更聪明的模型"解释一切（模型不是护城河，Karpathy：90% 的 AI 账单是浪费的上下文）。
- ❌ 先做全学科全年级（质量方差会毁掉口碑，先做一个窄楔子的极致）。
- ❌ 把体验判断当技术决策（你 `docs/agent-architecture.md` 已总结这类返工）。

## 4. 产品路线图（让 CEO 眼睛一亮的三步）

**叙事主线：从"生成项目的工具"升级为"可度量的因材施教引擎"。**

| 阶段 | 产品动作 | 可展示物（Demo） | 目标指标 |
| --- | --- | --- | --- |
| P1（0–4 周）**把 AI 用对** | 真压缩 + 结构化学习笔记 + 评估去正则 | 同一段对话，改造前后对比：输入 token ↓50%，卡点识别准确率 ↑ | 答案泄露率、单对话成本 |
| P2（5–10 周）**把学习做成资产** | 知识追踪（BKT）+ skill gating + 掌握图谱 | 学生"掌握图谱"页 + 教师全班热力图 | 人均掌握知识点增量 |
| P3（11–16 周）**把增长接上** | 作品广场当增长回路 + 成长报告叙事化 + 试点校样板 | 一所示范校的完整案例（数据 + 家长反馈） | 续费率 / 转介绍数 |

**北极星指标**：每学生每周"新增学习证据 + 掌握知识点增量"（过程性、抗刷分）。
**护栏指标**：答案泄露率（越低越好）、AI 成本/学生/月、教师周耗时（<10 分钟）。
**商业要点**：单位经济先跑通（单生月 token 成本 vs 客单价）；毛利路径对齐你 7 年模型（59.5%→92%），但增长假设按调研**下调**——瓶颈在分发不在产品。

## 6. 个人指导：你要补的 5 项能力（针对你的背景）

你是**游戏开发者 + 科创**，这条路其实顺得惊人——很多能力可直接迁移：

| 游戏开发能力 | 迁移到本项目的能力 |
| --- | --- |
| Playtesting / 手感调优 | **Eval / 黄金用例 / AI 质量门禁** |
| 玩法循环设计 | **学习闭环与参与度设计** |
| 关卡设计 | **课程与里程碑设计（curriculum）** |
| 生产管线（asset pipeline） | **多 Agent 生产线 + 提示词资产库** |
| 性能预算（帧预算） | **上下文/token 预算** |

**要补的 5 项能力：**
1. **上下文工程**（最高优先）：读懂 Anthropic 那篇 + 亲手把 T1/T2 做一遍。这是你和普通"调 prompt 的人"拉开差距的地方。
2. **评估与度量（Eval）**：把"AI 好不好"变成可回归测试的数字。这是你游戏 QA 思维的直接迁移，也是 CEO 最买账的"证据"。
3. **学习者建模基础**：BKT/IRT 的思想（会查表+会实现最小版即可，不必读论文）。
4. **单位经济与财务语言**：读懂你那份 7 年模型，能自己算"单生 token 成本 / 客单价 / 毛利 / CAC"。CEO 用这个语言思考。
5. **分发/GTM**：调研反复证明增长瓶颈在分发。练"示范校样板 + 教师社群 + 作品广场"的增长回路。

**每周操作系统（建议 time-box）：**
- 周一 30min：定本周 1 个可验收的技术改动（对应 T1–T9 之一）。
- 周三 60min：读一手材料（Anthropic 博客 / 论文 / 竞品）并写 5 行笔记进 `memory/`。
- 周五 60min：跑 eval + 更新指标面板；写下"这周学到的一条 invariants/symptom"。
- 周末 60min：对外输出（一篇短文/一个 demo），喂养分发回路。

## 7. 对 CEO 的汇报打法（imprint 的关键）

### CEO 关心三件事，按这个顺序讲
1. **市场与机会**（这门生意多大、为什么是现在）。
2. **我们凭什么赢**（楔子 + 护城河，而不是功能清单）。
3. **你要什么**（资源/决策/时间，以及你会交付什么数字）。

### 一页纸结构（先写这一页，再扩成 6-pager）
```
标题：把 1:1 辅导变成可规模化产品（Bloom 2-Sigma × AI）
1. 问题：因材施教做不起（1:1 辅导贵到无法规模化）
2. 洞察：LLM 让 1:1 边际成本趋零；但通用聊天会让孩子把思考外包（技能退化）
3. 方案：教师定主题 → AI 生成专属项目 → 苏格拉底导师（不直接给答案）→ 掌握图谱 → 报告
4. 证据：本地已跑通 X 校/Y 学生；答案泄露率 Z%；人均掌握知识点 +N
5. 护城河：学习者模型 + 反退化品牌 + 学校信任 + 作品广场增长回路
6. 单位经济：单生成本 / 客单价 / 毛利 / CAC（含 bear case）
7. 请求：资源 A、决策 B、下一步 C（带时间点）
```

### 三个能立刻加分的"信任动作"
1. **主动认领一个指标并动它**：比如"答案泄露率从 X 降到 Y"，用数据说话。
2. **带去风险路径**：灰度 → 试点 → 全校 → 多校 + 合规意见（CEO 最怕不可控）。
3. **展示机械门禁**：给他看 G1–G7 与"打 tag 前必过 build"——说明你**不靠运气交付**。

### 要避免的坑
- 别用功能清单代替价值主张（"我又加了 5 个功能" 是工程师语言）。
- 别把技术复杂度当卖点（CEO 只关心结果与风险）。
- 别在还没数据时谈规模化（先拿一个样板校的硬数据）。
- 别承诺自己控不了的事（增长/渠道/合规要单独列风险）。
