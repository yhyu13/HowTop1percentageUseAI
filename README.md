# AI Top 1% Playbook — 前 1% AI 用户使用习惯研究与应用

> 目标:持续调研国内外前 1% AI 使用者的习惯、工作流与杠杆模式,并翻译成我可落地的行动,覆盖以下领域:
> **游戏开发 · 科创 · AIGC · 产品 · 投资 · 编程架构 · AI 教育 tutor 创业**

## 这个仓库是什么

这是一个长期跟踪仓库,由我和 AI 伙伴「前 1% AI 用户使用习惯探究」共同维护:

- 每次对话中产生的调研、结论、行动清单,都会沉淀到这里并 git 提交
- `journal/` 记录对话要点与决策,`docs/research/` 存放深度调研报告
- 所有报告基于真实搜索来源,标注 URL,可回溯验证

## 目录结构

```
docs/
  research/    深度调研报告(前1%用户习惯、工作流、案例)
  profiles/    具体人物/公司画像(超级个体、AI-native 公司)
  workflow/    可直接套用的 AI 工作流与清单(SOP)
notes/         灵感、碎片、待验证想法
journal/       对话日志与阶段性结论
templates/     复用模板(调研模板、人物画像模板等)
```

## 使用方式

1. 我随时向 AI 伙伴提出问题或方向
2. 伙伴调研(联网搜索)→ 结论写入对应目录 → git commit
3. 每季度回顾 `journal/`,把「知道了」变成「在做的」
